# dgs-ai-first — Trilha de Certificação AI First (DGS)

Repositório com as resoluções dos exercícios práticos da Trilha DGS de IA First.

## Estrutura

O repositório é organizado por **Cenário-Âncora** → **Papel** → **Exercício**, seguindo a numeração oficial da trilha.

```
dgs-ai-first/
└── cenario-1-entendimento-contexto/
    └── product-specialist/
        ├── exercicio-1.1-mapeamento-intent/
        ├── exercicio-1.2-jornada-atendente/
        └── exercicio-1.3-spec-requisitos-rag/
```

Cada pasta de exercício contém um `README.md` com a estrutura padrão (contexto, tarefa realizada, prompts usados, outputs obtidos, análise crítica) e os artefatos de apoio (prints, diagramas, planilhas) quando aplicável.
